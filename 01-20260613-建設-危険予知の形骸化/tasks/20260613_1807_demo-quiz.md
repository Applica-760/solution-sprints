# demo本体：建設KYクイズ（データのみ・自己採点）

## 目的・前提・方針案
- 目的: その日の作業に応じた危険予知クイズを出し、作業員が能動的に危険を考えるdemoを動かす
- 前提（確定済）: FastAPI（データ＋出題）＋薄いNext.js（1画面）／venvはSprint内／RAGなし／LLMなし（データのみ・自己採点）
- データ: `demo/api/fetch_data.py` の `load()` が返す建設業3,900件（situation/accident_type/agent/work/age/month）
- 体験: プリセットのキーワード（作業内容）を1つ選択 → 該当する災害状況を抽出 → 起こりうる事故を選択肢から選ぶ → 公式の事故の型＋起因物を開示して答え合わせ
- 割り切り: スコアリング履歴・出題スケジューリング・レベル別出し分けは作らない（2本目以降）

## 設計メモ（実装前の確定事項）
- キーワード→フィルタ: 作業キーワードを `situation` への部分一致で引く（初期案: 高所/足場, 掘削/土砂, 重機/クレーン, 電動工具, 解体, 運搬/玉掛）。各キーワードに一致語リストを持たせる
- 出題: 抽出レコードから1件→ `situation` 提示。選択肢は `事故の型分類名` の全カテゴリ（約8種）から正解＋ダミー。正解＝当該レコードの accident_type
- 答え合わせ: 正誤＋ accident_type＋ agent を開示
- 既知の限界（v1許容）: `situation` が結末を含むと答えが漏れる。公式ラベルは隠すが状況文の結末漏れは許容。簡易マスク（末尾の結末節除去）は任意ステップ

### 着手時に確定した事項（実データ検証済み・離席中の自律判断）
- キーワード6分類は実データでヒット件数を確認済み（高所・足場1131 / 掘削・土砂235 / 重機・クレーン382 / 電動工具223 / 解体497 / 運搬・荷役310件）。一致語は下記実装の `KEYWORDS` で確定
- ダミー選択肢の母集団: 主要8型（墜落転落・はさまれ巻き込まれ・転倒・飛来落下・切れこすれ・激突され・激突・崩壊倒壊）から正解を除いてサンプル。選択肢計4（正解1＋ダミー3）
- 正解の配信: demo（自己採点）の最簡実装として `/quiz` 応答に正解と解説（accident_type/agent）を同梱し、フロントが回答後に開示する。出題スケジューリング/隠蔽は2本目以降。理由＝サーバ状態を持たず1人テストを最短で通すため
- 結末漏れマスク: situation末尾の結末節（受傷/負傷/死亡 等の語を含む文末1節）を粗く除去する軽量版を実装。誤除去のリスクがあるため保守的に1節のみ
