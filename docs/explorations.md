## 教育（日本の教育現場中心）

調査日: 2026-06-14

### スキャン

**人手・働き方**
- 教員不足が深刻化。文科省実態調査で「教師不足」3,827人、4年で倍増（[ReseEd 2026-03](https://reseed.resemom.jp/article/2026/03/06/12764.html) / [文科省](https://www.mext.go.jp/a_menu/shotou/kyoin/mext_00003.html)）。新任の1年以内離職4.9%、特別支援学級の急増が要因（[教師不足について：文科省](https://www.mext.go.jp/a_menu/shotou/kyoin/mext_00004.html)）
- 校務DX。記述採点・調査書作成・おたより/アンケートのペーパーレス化が事例。「小さな改善の積み重ね」「身近な業務から」が定石（[ジチタイワークス](https://jichitai.works/articles/3059) / [インテック](https://www.intec.co.jp/column/schoolcloud-04.html)）。東京都「次世代校務DXプロジェクト」始動（[シン・トセイ](https://shintosei.metro.tokyo.lg.jp/post_seisakudx-1-2_251001/)）

**部活動の地域移行**
- 2026年度から「改革実行期間」入り。神戸市は2026年9月から休日・平日とも完全移行、伊丹市・播磨町も移行予定。指導者確保・日程・送迎・大会手続きの調整負荷が課題（[大阪経済大](https://www.osaka-ue.ac.jp/topics/reesearch/20250616_5588.html) / [スポーツ庁](https://sports.go.jp/tag/school/post-148.html) / [ジチタイワークス](https://jichitai.works/articles/3362)）

**学び・個別最適化**
- 生成AIがEdTechの中心。記述式の自動採点＋個別フィードバック、AIドリルのレベル別配信が具体例。「教員は人にしかできない指導へ」（[マナビタス 2026動向](https://manabitasu.jp/blog/2026/01/09/edtech-elearning-trends-and-use-cases-2026/) / [SHIFT AI](https://shift-ai.co.jp/blog/4001/) / [すらら](https://surala.jp/school/column/4088/)）
- NEXT GIGA: 端末更新は2025年に調達72%集中、価格高騰を懸念。CBTの学習データを政策に利活用する構想（[MM総研調査](https://edtechzine.jp/article/detail/11429) / [文科省WG取りまとめ](https://www.mext.go.jp/content/20240805-mxt_jogai02-000037400_01.pdf)）

**不登校**
- 2024年度の小中不登校は35万人で過去最多・12年連続増。教員不足で支援が手薄。フリースクール/オンライン学習での機会提供が論点（[Impress Watch](https://edu.watch.impress.co.jp/docs/news/2059264.html) / [JTB特集](https://www.jtbbwt.com/education/trend/detail/id=4477)）
