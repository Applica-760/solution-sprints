# Sprintテーマ候補

命名規約: `NN-YYYYMMDD-産業-課題`（1行1テーマでストック。着手時に行頭へ `[NN-YYYYMMDDで着手]` を付す）
未精製の原石（ニュース・ソリューション・所感）は [explorations.md](explorations.md) に溜め、育ったらここへ昇格する。

## 記入雛形（コピーして使う）

```
- 産業-課題（1行で）
  - 背景: なぜ課題か。雑な定量・出典
  - デモデータ: 入手可能性。1日サイズに収まるか
  - 備考: 要検討・捨てる方向など（任意）
```
